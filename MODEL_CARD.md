# Model Card — SignVision AI

## Model summary

A convolutional image classifier for the American Sign Language (ASL) alphabet,
used as the subject of an adversarial-robustness study.

| | |
|---|---|
| **Task** | Single-image classification of ASL alphabet gestures |
| **Architecture** | VGG16 convolutional base (`keras.applications`, `include_top=False`) + Flatten + Dense softmax head |
| **Input** | 50×50 RGB images, pixel values scaled to `[0, 1]` |
| **Output** | Probability distribution over classes |
| **Classes** | 29 (letters A–Z plus `delete`, `nothing`, `space`) |
| **Framework** | TensorFlow 2.19 / Keras 3.11 |
| **Weights** | `streamlit_app/assets/models/ASL_DNN.weights.h5` |

## Intended use

Educational and portfolio demonstration of (a) image classification and (b) how
adversarial perturbations affect a classifier and how adversarial training
mitigates them. It is **not** a production communication tool and **not** a
real-time or continuous sign-language translator.

## Training data

The [ASL Alphabet dataset](https://www.kaggle.com/datasets/grassknoted/asl-alphabet):
~87,000 images (~3,000 per class) across 29 classes, captured against a uniform
background under consistent lighting.

## Performance

- **Baseline test accuracy:** ~93.6% on clean images. This is traceable to the
  training logs in `results/logs.npy` (final `val_accuracy` ≈ 0.937 over 10
  epochs).
- **Adversarial robustness:** the baseline model is highly susceptible to FGSM
  perturbations (high attack success rate). After adversarial training, natural
  accuracy decreases modestly while accuracy on adversarial inputs improves
  substantially. This is the expected robustness trade-off. These robustness figures
  come from the CMSE 890 adversarial-training experiments and are not currently
  regenerated by the code in this repository.

## Adversarial robustness details

- **Attack studied:** Fast Gradient Sign Method (FGSM), implemented with
  [Foolbox](https://github.com/bethgelab/foolbox). Projected Gradient Descent
  (PGD) was also explored during the project.
- **Defense studied:** adversarial training (retraining on FGSM-perturbed
  examples).

## Known limitations

- **29 vs. 30 output units.** The saved weights expose 30 output units, but the
  dataset has only 29 labelled classes. The 30th unit is an unused training
  artifact. The app builds the model with 30 units so the weights load cleanly,
  but only surfaces the 29 real labels and guards against the unused index (see
  `streamlit_app/config.py`).
- **Domain shift.** Trained on a single, uniformly-lit dataset. Accuracy on
  real-world photos with varied lighting, backgrounds, skin tones, and hand
  positions is expected to be lower.
- **Alphabet only.** Recognizes individual alphabet/control gestures, not words,
  phrases, or the grammar of signed languages.

## Ethical considerations

Tools that touch accessibility and communication should not overstate their
reliability. This project is deliberately framed as a research demonstration, and
its limitations above are stated plainly so it is not mistaken for an assistive
device suitable for real communication.
